# Тестовый фреймворк на Playwright и TypeScript со встроенным сервером Node.js

Автономный фреймворк для сквозного тестирования веб-приложений, построенный на базе Playwright и TypeScript. Чтобы полностью исключить падения тестов из-за нестабильного интернета и блокировок, в проект интегрирован собственный легковесный локальный веб-сервер на Node.js.

##  Стек технологий
* **Язык:** TypeScript (строгая типизация)
* **Инструмент автоматизации:** Playwright Test Runner
* **Архитектурные паттерны:** Page Object Model (POM), Data-Driven Testing (DDT)
* **Экосистема:** Node.js, HTTP-сервер, CI/CD через GitHub Actions

## Ключевые архитектурные особенности
* **Встроенный тестовый сервер:** Проект содержит файл `server.js`, который поднимает локальное приложение авторизации. Тесты запускаются на `http://localhost:3000`, пролетают быстрее чем за секунду (~700мс на тест) и на 100% защищены от сетевых сбоев.
* **Page Object Model (POM):** Интерфейс приложения, локаторы элементов страниц и цепочки действий пользователей полностью изолированы внутри классов в директории `pages/`.
* **Data-Driven Testing (DDT):** Параметризация негативных сценариев (валидация логина/пароля) реализована через лаконичные циклы `for...of` нативного TypeScript.
* **Автоматизация жизненного цикла (CI/CD):** В конфигурации `playwright.config.ts` настроен параметр `webServer`. При запуске тестов в облаке GitHub Actions сам автоматически поднимает фоновое Node.js приложение, прогоняет тесты и корректно тушит сервер по завершении работы.

## Инструкция по локальному запуску
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установите зависимости проекта:
   ```bash
   npm install
   ```
3. Запустите тесты в консольном (Headless) режиме:
   ```bash
   npx playwright test
   ```
4. Запустите тесты в интерактивном графическом интерфейсе (рекомендуется):
   ```bash
   npx playwright test --ui
   ```
